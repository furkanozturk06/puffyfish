# Puffy Fish (Şiş Balık)

A pixel-art arcade game about a pufferfish. Tap to puff up one level at a time, outgrow the big fish and deflate to eat the small ones.

## How to play

- Every tap puffs you up one level (0–5). Stop tapping and you slowly deflate.
- Each predator shows its size number. Match or beat it to survive.
- Match it exactly for a close call: +5 points and a combo multiplier.
- Fully deflate (level 0) to eat small fish and keep your hunger bar from running out.
- Spend coins in the shop on new pufferfish skins.

## Run

Open `index.html` in a browser. Best played in landscape.
